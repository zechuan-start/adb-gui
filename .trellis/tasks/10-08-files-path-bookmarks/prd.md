# 文件页路径收藏与颜色标注

> 状态: brainstorm 中. 待确认问题 Q1-Q8 已列出, 等用户统一回复后更新本文件, 再写 design / implement.
> 来源: zechuan-start/adb-gui#10 第 8 条 "加上路径收藏、标注颜色功能, 便于访问常用路径". 反馈者提到的参考实现 HaujetZhao/ADB-Browser 不在本次调研范围内, 未参考.

## 产品形态

文件页 (03) 的导航辅助: 用户把常去的设备目录收藏起来, 一键跳回; 给收藏标一个颜色, 在长列表里快速认出来.

它不是文件标签/搜索系统, 也不改设备上的任何文件.

## 已确认事实 (来自代码)

- 导航入口: 顶栏 (43px) 依次是 回起始目录 / 上一级 / 路径输入框 / 复制路径 / 跳转 / 刷新; 下面一行是面包屑, 右侧是排序、新建目录、上传 (`DeviceFileManager.tsx`).
- 右侧详情面板对选中项已有 "复制路径 / 打开目录 / 下载" 按钮, 选中目录时可以放 "收藏" 按钮.
- 文件列表用 `@tanstack/react-virtual`, 行高固定 38px; 行内名称前已有图标位, 新增标记不能改变行高. 选中行用左侧 3px `note` 色条标识.
- 全应用目前没有右键菜单 (`onContextMenu` 无使用).
- 设备有跨 USB / 无线一致的标识: `deviceCacheKey` = `device_id` (`ro.serialno`) ?? `alias_identity` ?? `serial` (`src/lib/device.ts`), 按设备区分在技术上可行.
- 主题只有语义色 (`note/ok/warn/err`), 没有一组可选的标注色板; 有亮 / 暗两套主题 (`.dark`).
- 持久化:
  - `lib/settings.ts` 的 `files` 分区带校验、`SETTINGS_VERSION` 迁移和设置面板的 "恢复默认" 重置计划 (`settingsSections.ts`). 收藏如果放进这里, 重置文件设置会一并清空收藏.
  - `store/ui.ts` 的 persist 分区存放布局状态 (面板、日志高度、工具顺序).
- 设备路径只做字面规范化 (去掉重复 `/`、`.`、`..`), 不解析软链接 (`normalize_device_path`, `device_files.rs`). 默认目录是 `/sdcard/Download`.
- 现在跳到常用目录只能: 手动输入路径、逐级进入, 或在设置里配置一个起始目录 (预设 下载 / 内部存储 / 相机 / 自定义).

## 已确认决定

- 颜色只作用于收藏, 不给未收藏的文件 / 目录上色. (用户确认, 2026-10-09)

## 已定 (实现约束, 无需用户确认)

- 只有目录可以收藏, 文件不行.
- 收藏按规范化后的路径字符串匹配, 不解析软链接: `/sdcard/Download` 和 `/storage/emulated/0/Download` 算两个不同的收藏. 解析软链接要对每个目录多跑一次 adb 命令, 不值得.
- 没有在线设备时, 收藏列表仍可查看和编辑, 只是不能跳转.
- 收藏单独存储, 不放进 `settings.files`, 避免被 "恢复默认" 连带清空.

## 建议范围

### P0 (本任务)

- 收藏当前目录: 路径栏加星标按钮, 已收藏时为实心并显示其颜色. 已收藏时再点的行为见 Q3.
- 详情面板选中目录时, 也可以直接收藏 / 取消收藏, 不必先进入.
- 收藏列表入口 (形式见 Q2): 列出所有收藏, 每项显示 颜色点 + 目录名 + 完整路径; 点击跳转.
- 列表内每项可以改颜色、删除.
- 颜色: 预设色板 + 无色 (色板与显示方式见 Q5), 亮 / 暗主题下都清晰可辨.
- 文件列表中, 有颜色的收藏目录显示对应颜色, 行高不变 (无色收藏是否标记见 Q4).
- 收藏的路径在当前设备不存在时, 走现有的目录错误 + 重试流程, 不自动删除收藏.
- 重启应用后收藏和颜色保持.
- 中英文文案同步.

### P1 (后续, 不在本任务, 见 Q8)

- 收藏自定义名称 (默认用目录名, 同名时靠完整路径区分).
- 收藏拖拽排序.
- 快捷键收藏当前目录.
- 把某个收藏设为起始目录.

### 不做

- 给未收藏的任意文件 / 目录上色.
- 给任意文件打多标签或按标签搜索.
- 收藏导入导出、云同步.
- 修改设备文件或目录本身的任何属性.

## 待确认 (附建议)

- Q1 收藏全局共享还是按设备区分. 建议: 全局共享.
- Q2 收藏列表入口形式: 下拉菜单 / 常驻收藏栏 / 侧边栏. 建议: 路径栏左侧的下拉菜单.
- Q3 已收藏时点星标: 直接取消, 还是弹出小面板 (选颜色 + 取消收藏). 建议: 弹出小面板.
- Q4 新收藏默认颜色, 以及无色收藏在文件列表里是否标记. 建议: 默认无色, 文件列表只标记有颜色的收藏.
- Q5 色板与显示方式. 建议: 红 / 橙 / 黄 / 绿 / 蓝 / 紫 6 色 + 无色, 文件列表中给文件夹图标上色.
- Q6 收藏列表排序与数量上限. 建议: 按添加顺序, 新的排在最后; 不设上限, 列表超过约 10 条时内部滚动.
- Q7 设置面板是否需要收藏管理或清空入口. 建议: 不加, 管理都在收藏列表里; "恢复默认" 不清空收藏.
- Q8 P1 各项是否都放到以后. 建议: 都放到以后.

## 验收标准 (草案, Q1-Q8 确认后修订)

- [ ] 进入某目录后点星标即可收藏, 收藏列表中出现该路径.
- [ ] 已收藏的目录可以取消收藏.
- [ ] 详情面板选中目录时可以收藏 / 取消收藏.
- [ ] 从收藏列表点击可直接跳到该目录.
- [ ] 为收藏设置颜色后, 文件列表中该目录显示同色标记, 亮暗主题都可辨, 行高不变.
- [ ] 收藏可在列表中改颜色、删除.
- [ ] 重启应用后收藏和颜色保持; 设置 "恢复默认" 后收藏仍在.
- [ ] 收藏目录被删除后点击收藏, 显示现有的目录错误与重试, 收藏仍保留.
- [ ] 没有在线设备时可以查看和编辑收藏, 跳转不可用.
- [ ] 中英文界面文案完整.
