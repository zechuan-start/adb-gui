# 文件页路径收藏与颜色标注

> 状态: brainstorm 中, 范围已给出建议, 逐条确认待决问题后再写 design / implement.
> 来源: zechuan-start/adb-gui#10 第 8 条 "加上路径收藏、标注颜色功能, 便于访问常用路径". 反馈者提到的参考实现 HaujetZhao/ADB-Browser 不在本次调研范围内, 未参考.

## 产品形态

文件页 (03) 的导航辅助: 用户把常去的设备目录收藏起来, 一键跳回; 给收藏标一个颜色, 在长列表里快速认出来.

它不是文件标签/搜索系统, 也不改设备上的任何文件.

## 已确认事实 (来自代码)

- 导航入口: 顶栏 (43px) 依次是 回起始目录 / 上一级 / 路径输入框 / 复制路径 / 跳转 / 刷新; 下面一行是面包屑, 右侧是排序、新建目录、上传 (`DeviceFileManager.tsx`).
- 右侧详情面板对选中项已有 "复制路径 / 打开目录 / 下载" 按钮, 选中目录时可以放 "收藏" 按钮.
- 文件列表用 `@tanstack/react-virtual`, 行高固定 38px; 行内名称前已有图标位, 新增标记不能改变行高.
- 全应用目前没有右键菜单 (`onContextMenu` 无使用), 给任意目录上色需要新增交互方式.
- 设备有跨 USB / 无线一致的标识: `deviceCacheKey` = `device_id` (`ro.serialno`) ?? `alias_identity` ?? `serial` (`src/lib/device.ts`), 按设备区分在技术上可行.
- 主题只有语义色 (`note/ok/warn/err`), 没有一组可选的标注色板; 有亮 / 暗两套主题 (`.dark`).
- 持久化:
  - `lib/settings.ts` 的 `files` 分区带校验、`SETTINGS_VERSION` 迁移和设置面板的 "恢复默认" 重置计划 (`settingsSections.ts`). 收藏如果放进这里, 重置文件设置会一并清空收藏.
  - `store/ui.ts` 的 persist 分区存放布局状态 (面板、日志高度、工具顺序).
- 现在跳到常用目录只能: 手动输入路径、逐级进入, 或在设置里配置一个起始目录 (预设 下载 / 内部存储 / 相机 / 自定义).

## 建议范围

### P0 (本任务)

- 收藏当前目录: 路径栏加星标按钮, 已收藏时为实心并显示其颜色, 再点取消收藏.
- 详情面板选中目录时, 也可以直接收藏 / 取消收藏, 不必先进入.
- 收藏列表入口 (路径栏左侧): 下拉列出所有收藏, 每项显示 颜色点 + 目录名 + 完整路径; 点击跳转.
- 列表内每项可以改颜色、删除.
- 颜色: 6 个预设色 + 无色, 亮 / 暗主题下都清晰可辨.
- 文件列表中, 被收藏的目录在图标处显示对应颜色, 行高不变.
- 收藏的路径在当前设备不存在时, 走现有的目录错误 + 重试流程, 不自动删除收藏.
- 重启应用后收藏和颜色保持; 设置里 "恢复默认" 不清空收藏.
- 中英文文案同步.

### P1 (后续, 不在本任务)

- 收藏自定义名称 (默认用目录名, 同名时靠完整路径区分).
- 收藏拖拽排序 (P0 按添加顺序).
- 快捷键收藏当前目录.

### 不做

- 给未收藏的任意文件 / 目录上色 (需要新增右键菜单和独立的颜色存储).
- 给任意文件打多标签或按标签搜索.
- 收藏导入导出、云同步.
- 修改设备文件或目录本身的任何属性.

## 待确认

- 颜色标注只作用于收藏, 还是也可以标注未收藏的目录 / 文件. (建议: 只作用于收藏)
- 收藏全局共享, 还是按设备区分. (建议: 全局共享)
- 收藏数量是否设上限.

## 验收标准 (草案)

- [ ] 进入某目录后点星标即可收藏, 收藏列表中出现该路径; 再点星标取消.
- [ ] 详情面板选中目录时可以收藏 / 取消收藏.
- [ ] 从收藏列表点击可直接跳到该目录.
- [ ] 为收藏设置颜色后, 文件列表中该目录显示同色标记, 亮暗主题都可辨, 行高不变.
- [ ] 收藏可在列表中改颜色、删除.
- [ ] 重启应用后收藏和颜色保持; 设置 "恢复默认" 后收藏仍在.
- [ ] 收藏目录被删除后点击收藏, 显示现有的目录错误与重试, 收藏仍保留.
- [ ] 中英文界面文案完整.
