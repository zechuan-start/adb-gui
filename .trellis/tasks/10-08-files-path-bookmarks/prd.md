# 文件页路径收藏与颜色标注

> 状态: 需求草稿, 待 brainstorm 收敛范围后再写 design / implement.
> 来源: zechuan-start/adb-gui#10 第 8 条 "加上路径收藏、标注颜色功能, 便于访问常用路径", 反馈者提供参考实现 https://github.com/HaujetZhao/ADB-Browser.

## 产品形态

文件页 (03) 的导航辅助: 用户把常去的设备目录收藏起来, 一键跳回; 给收藏或目录标一个颜色, 在长列表里快速认出来.

它不是文件标签/搜索系统, 也不改设备上的任何文件.

## 已确认事实

- 现在只能手动输入路径、逐级进入, 或在设置里配置一个起始目录.
- 文件偏好 `FilePreferences` 只有 `sortBy`、`sortDirection`、`directoriesFirst`、`showHidden`、`startDirectory` (`src/lib/settings.ts`).
- 持久化有两条路: `lib/settings.ts` (带 `SETTINGS_VERSION` 和 `settingsSections.ts` 的重置计划) 和 `store/ui.ts` 的 persist 分区; 拖拽排序任务曾按 "布局状态放 ui store" 做过取舍.
- 文件列表使用虚拟滚动 (`DeviceFileManager.tsx`), 新增行内标记需要保持行高不变.

## P0 候选范围 (待确认)

- 收藏当前目录; 已收藏时可以取消.
- 路径栏附近的收藏入口, 列出收藏, 点击跳转到该目录.
- 收藏可以删除, 可以设置一个预设颜色.
- 文件列表中, 被收藏的目录显示对应颜色标记.
- 收藏的路径在设备上不存在时, 跳转走现有的列表错误 + 重试流程, 不自动删除收藏.
- 中英文文案同步.

## 不做

- 给任意文件打多标签或按标签搜索.
- 收藏导入导出、云同步.
- 修改设备文件或目录本身的任何属性.

## 继续实现前需要确认

- 收藏按设备 (serial / 型号) 区分, 还是全局共享.
- 颜色标注只作用于收藏, 还是也可以标注未收藏的目录/文件.
- 存储放 `lib/settings.ts` 还是 `store/ui.ts`, 设置面板里是否需要管理入口和重置.
- 收藏是否支持自定义名称和拖拽排序, 数量是否设上限.

## 验收标准 (草案)

- [ ] 进入某目录后可一键收藏, 收藏入口中出现该路径.
- [ ] 从收藏入口点击可直接跳到该目录.
- [ ] 为收藏设置颜色后, 文件列表中该目录显示同色标记, 亮暗主题都可辨.
- [ ] 重启应用后收藏和颜色保持.
- [ ] 收藏目录被删除后点击收藏, 显示现有的目录错误与重试, 收藏仍保留.
