# 文件页路径收藏与颜色标注

> 状态: 规划已审阅通过 (2026-10-09), 进入实现.
> 来源: zechuan-start/adb-gui#10 第 8 条 "加上路径收藏、标注颜色功能, 便于访问常用路径". 反馈者提到的参考实现 HaujetZhao/ADB-Browser 不在本次调研范围内, 未参考.

## 产品形态

桌面工具型 app 里文件页 (03) 的导航辅助: 用户把常去的设备目录收藏起来, 一键跳回; 给收藏标一个颜色, 在长列表里快速认出来; 也可以把某个收藏设为每次打开文件页时的起始目录.

它不是文件标签 / 搜索系统, 不是书签管理后台, 也不改设备上的任何文件.

## 用户工作流

- 常去 `/sdcard/DCIM/Camera`、`/sdcard/Android/data/<包名>/files` 这类深目录的人: 第一次逐级进入后点星标收藏, 之后从收藏列表一步跳到.
- 同时调试多台手机的人: 收藏所有设备共用, 换设备后直接点收藏; 某台设备上没有的目录会报错, 收藏不受影响.
- 每次都从同一个目录开始工作的人: 把那个收藏设为起始目录; 换到没有这个目录的设备时自动回到下载目录, 不用每次手动处理报错.

## 已确认事实 (来自代码)

- 导航入口: 顶栏 (43px) 依次是 回起始目录 / 上一级 / 路径输入框 / 复制路径 / 跳转 / 刷新; 下面一行是面包屑, 右侧是排序、新建目录、上传 (`DeviceFileManager.tsx`).
- 右侧详情面板对选中项已有 "复制路径 / 打开目录 / 下载" 按钮.
- 文件列表用 `@tanstack/react-virtual`, 行高固定 38px. 普通目录图标是紫色描边 (`text-note`), 可预览图片是绿色 (`text-ok`), 其他文件和软链接是灰色 (`text-ink3`). 选中行用左侧 3px `note` 色条.
- 全应用目前没有右键菜单 (`onContextMenu` 无使用).
- 设备有跨 USB / 无线一致的标识 `deviceCacheKey` (`src/lib/device.ts`); 本任务按 "所有设备共用" 决定, 不使用它.
- 主题语义色: `note` 紫 / `ok` 绿 / `warn` 琥珀 / `err` 红, 亮暗两套 (`src/index.css`).
- 持久化:
  - 设置存 `localStorage` 的 `adb-gui-settings`, `files` 分区带校验和 "恢复默认" 重置计划 (`lib/settings.ts`, `settingsSections.ts`).
  - 布局状态存 `adb-gui-ui` (`store/ui.ts`).
- 设备路径只做字面规范化 (去掉重复 `/`、`.`、`..`), 不解析软链接 (`normalize_device_path`). 不传路径时 Rust 打开 `/sdcard/Download`.
- 目录打不开时, 后端区分 `files.notDirectory` (不存在或不是目录) 和 `files.directoryPermission` (无权限); 设备断开等走其他错误码.
- 起始目录只在进入文件页、切换设备、点 Home 时读取. 现有规范明确写着 "起始目录打不开时显示真实错误, 不自动回退" (`.trellis/spec/frontend/settings-clipboard.md`), 本任务按用户要求修改这条规则.
- 组件测试没有 jsdom, 只能 `renderToStaticMarkup`; 判断逻辑要下沉到纯函数.

## 已确认决定 (用户, 2026-10-09)

1. 颜色只作用于收藏, 不给未收藏的文件 / 目录上色.
2. 收藏所有设备共用一份.
3. 收藏列表入口由实现方决定, 兼顾美观和便捷: 采用路径栏左侧 (Home 右边) 的下拉列表. 理由: 不额外占用文件页高度, 收藏多了也装得下, 和现有下拉菜单风格一致.
4. 已收藏时点星标: 弹出小面板 (改颜色 / 设为起始目录 / 取消收藏), 不直接取消.
5. 新收藏默认无色; 文件列表只标记有颜色的收藏, 无色收藏和普通目录外观一样.
6. 色板避开现有语义色, 亮暗主题都清晰: 橙 / 青柠 / 青 / 蓝 / 粉 5 色 + 无色 (见 design.md 色板一节). 不用红、黄、紫, 因为它们分别是错误、警告和普通目录的颜色.
7. 收藏列表按添加顺序, 新的排在最后; 不设数量上限, 超过约 10 条时列表内部滚动.
8. 设置面板不加收藏管理入口; 设置 "恢复默认" 不清空收藏.
9. "把收藏设为起始目录" 纳入本任务. 起始目录在当前设备上打不开时, 回到默认的下载目录.
   - 只是这一次打开下载目录, 不改设置里保存的起始目录 (其他设备可能有这个目录). 用户已确认此理解.
10. 自定义名称、拖拽排序、快捷键收藏放到以后.

## 已定 (实现约束)

- 只有目录可以收藏, 文件不行.
- 收藏按规范化后的路径字符串匹配, 不解析软链接: `/sdcard/Download` 和 `/storage/emulated/0/Download` 算两个收藏.
- 没有在线设备时, 收藏列表仍可打开和编辑, 只是不能跳转.
- 收藏单独存储, 不放进 `settings.files`, 不受 "恢复默认" 影响, 不改 `SETTINGS_VERSION`.
- 取消收藏不弹确认: 只影响本机这条收藏和它的颜色, 可以重新收藏. 取消入口在弹出面板里, 不会一次误点就触发.
- 起始目录回退只发生在 "自动打开起始目录" 时 (进入文件页、切换设备、点 Home), 且只针对 `files.notDirectory` 和 `files.directoryPermission`. 手动输入路径、点面包屑、点收藏打不开时, 仍显示原来的错误 + 重试. 设备断开、adb 失败等错误不回退.

## 范围

### P0 (本任务)

| 能力 | 为什么是 P0 |
|---|---|
| 路径栏星标: 未收藏时一键收藏; 已收藏时弹出面板 | 收藏的唯一主入口 |
| 详情面板选中目录时可收藏 / 打开同一面板 | 不进入目录也能收藏, 成本只有一个按钮 |
| 收藏下拉列表: 跳转、编辑、空状态 | 收藏的价值在于一步跳回 |
| 5 色 + 无色, 文件列表实心彩色文件夹 | 反馈者明确提出的 "标注颜色" |
| 设为起始目录 + 打不开时回退到下载目录 | 用户本次明确纳入 |
| 持久化与损坏数据容错 | 收藏不能因为一次坏数据就让文件页不可用 |
| 中英文文案 | 项目双语约定 |

### P1 (后续, 不在本任务)

- 收藏自定义名称 (默认用目录名, 同名时靠完整路径区分).
- 收藏拖拽排序.
- 快捷键收藏当前目录.

### 不做

- 给未收藏的任意文件 / 目录上色, 右键菜单.
- 按设备区分收藏.
- 设置面板里的收藏管理或 "清空全部".
- 多标签、按标签搜索、导入导出、云同步.
- 修改设备文件或目录本身的任何属性.

## 验收标准

收藏与星标

- [ ] 在任一目录点路径栏星标, 该目录被收藏, 星标变为实心; 收藏列表末尾出现该目录.
- [ ] 已收藏目录的星标显示其颜色 (无色时为默认墨色实心).
- [ ] 已收藏时点星标弹出面板, 含 无色 + 5 色色板、"设为起始目录"、"取消收藏"; 点外部或按 Esc 关闭, 焦点回到星标.
- [ ] 详情面板选中一个目录时显示 "收藏"; 已收藏时显示 "已收藏", 点击打开同一面板. 选中文件时不显示.
- [ ] 根目录 `/` 也可以收藏, 列表中显示为 `/`.

收藏列表

- [ ] 点 Home 右边的收藏按钮打开下拉列表, 按添加顺序列出收藏, 每项显示 文件夹图标 (带颜色) + 目录名 + 完整路径.
- [ ] 当前所在目录对应的收藏高亮; 当前起始目录对应的收藏显示 Home 图标.
- [ ] 点击某项跳转到该目录并关闭列表.
- [ ] 每项的 "…" 在列表内切换到该项的编辑视图 (同星标面板), 可返回列表.
- [ ] 没有收藏时显示一行提示, 告诉用户点路径栏星标收藏.
- [ ] 超过约 10 条时列表内部滚动, 列表不超出窗口.
- [ ] 支持 方向键 / Home / End / Enter / Esc, Esc 后焦点回到触发按钮.
- [ ] 没有在线设备时可打开列表并编辑, 跳转项不可点.

颜色

- [ ] 有颜色的收藏目录在文件列表里显示实心彩色文件夹; 无色收藏和普通目录一样是紫色描边; 行高不变.
- [ ] 改颜色后, 文件列表、收藏列表、星标立即同步.
- [ ] 5 种颜色在亮暗主题的列表底色和悬停底色上对比度都不低于 3:1, 且和 紫 / 绿 / 琥珀 / 红 语义色可以区分.

起始目录

- [ ] 在面板里点 "设为起始目录", 设置面板的起始目录随之变为该路径; 点 Home 跳到该目录.
- [ ] 已是起始目录时, 该按钮显示为已设置状态且不可再点.
- [ ] 设置不可用 (设置读取失败) 时, "设为起始目录" 不可点.
- [ ] 起始目录在当前设备上不存在或无权限: 进入文件页、切换设备或点 Home 时自动打开下载目录, 列表上方显示一行提示 "起始目录 <路径> 在这台设备上打不开, 已打开下载目录", 带 "设置" 按钮; 设置里的起始目录不变.
- [ ] 上述提示在下一次导航或切换设备后消失.
- [ ] 手动输入路径、点面包屑或点收藏打开不存在的目录时, 仍显示原来的错误 + 重试, 不回退.
- [ ] 设备断开等非目录错误不触发回退.

持久化与容错

- [ ] 重启应用后收藏、顺序和颜色保持.
- [ ] 设置里 "恢复默认" 或重置文件分区后, 收藏仍在.
- [ ] 存储里的收藏数据损坏 (非数组、缺字段、相对路径、未知颜色、重复路径) 时, 丢弃或修正坏项, 文件页正常可用.
- [ ] 收藏的目录在设备上被删除后, 点击收藏显示现有错误与重试, 收藏仍保留.

文案

- [ ] 新增界面文字、提示、`aria-label`、`title` 中英文完整.
