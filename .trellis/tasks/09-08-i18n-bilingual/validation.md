# 集成验收记录

基线: 2026-09-08, macOS Darwin arm64, 当前分支 `claude/bilingual-project-plan-ng1o7s`. 五个子任务的实现已集成. 2026-09-08 用户要求按现有验证范围归档, 提交并推送翻译任务. 本文区分自动化检查, 原生验收和设备场景待验收项.

## 实现结果

- 提供 `system` / `zh-CN` / `en` 独立语言偏好, 默认按首个系统语言判断, 中文变体使用简体中文, 其余使用英文. 显式选择立即生效并持久化, 不进入设置 reset 计划.
- 使用同构 typed catalog, 将外壳, 六个设置分组, 六个工作区和原生确认参数迁入中英词典. 按 tools, streams, backend 拆词典模块, 禁止跨模块共享写入造成覆盖.
- 数字, 日期和时间使用当前 locale. 工具时间继续使用 24 小时制, 应用名排序使用当前 locale 的 collator; 设备应用名, 文件名, 包名和日志正文保持原样.
- Rust 命令与持续错误事件使用 `AppError` / `AppErrorPayload` 的 `code`, `params`, `detail`, `causes`. 原始诊断保留, 持久错误与 toast 在呈现时翻译. 原生错误码 253 项, 前端 backend schema 另含桥接错误.
- 语言切换不重启 Logcat, 性能与录屏轮询. 错误去重使用规范化 payload 的稳定标识, 避免对象错误被压成同一个 `[object Object]`.
- 修正英文截图按钮溢出, 允许具体按钮换行; 设置语言单独修改时不显示无作用的分组恢复按钮.
- README 分别引用两套七张截图. 新增可复用浏览器矩阵命令, 删除不再引用的七张顶层旧图.
