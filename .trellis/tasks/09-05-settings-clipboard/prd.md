# 统一设置与手动剪贴板

## 产品与目标

ADB GUI 是 Android 开发测试桌面工具. 保留现有工作台和设备上下文, 集中长期偏好, 支持电脑与当前 Android 设备之间按需传递剪贴板文本. 设置使用轻量弹窗, 不新增管理后台或控制台.

## 用户已确认

- 2026-09-05: 用户要求统一轻量设置, 评估并集中各页面已有设置和简单个性化配置.
- 2026-09-05: 用户明确要求扩展现有应用信息 DEX 来实现剪贴板, 不另行引入整套 scrcpy-server.
- 2026-09-05: 用户允许先做手动同步, 实时同步是可选后续能力.
- 2026-09-05: 用户授权规划设置和剪贴板任务, 随后通过 "OK开始执行" 明确授权实现.
- 2026-09-05: 用户选择第一版只做核心设置和剪贴板, 包含启动页/更新检查, 文件与应用排序, 生码默认值和目录选择延后.

## 规划时基线

- 现有主题和工作区布局已持久化; Logcat 视图和性能后台采集偏好尚未持久化.
- 截图保存后固定打开图片并定位目录, 录屏保存后固定打开视频.
- 同一个 app-info.dex 已支持元信息和图标两种查询, 通过 ADB 下发并使用 app_process 运行.
- 电脑端已有 Tauri 剪贴板插件. 当前连接设备为 Android 16, com.android.shell 的后台剪贴板读取权限已授予.
- 规划时手机剪贴板实际读写尚未验证, 原生 cmd clipboard 在当前设备上没有 shell 实现. 实施后已通过同一个 DEX 完成真机读写, 见 validation.md.

## 范围

### P0: 第一版必需

- 统一设置入口, 集中主题, Logcat 显示偏好, 工作区日志显隐, 性能后台采集等已有配置并保存用户选择. 这些是本次整合的直接目标.
- 为截图打开图片/定位目录和录屏打开视频提供独立开关. 这些直接影响日常工具操作, 实现边界较小.
- 提供启动页策略与启动检查更新开关. 默认恢复上次页面并自动检查更新, 保持现有首次升级行为.
- 提供发送到手机和复制到电脑两个手动文本操作. 复用现有 DEX, 只操作点击时选中的在线设备.
- 明确成功, 失败, 无文本, 设备断线和设备切换行为. 不保存剪贴板正文和历史.

### P1: 可选简单个性化

- 应用和文件排序, 隐藏文件显示, 生码默认类型与分隔符.
- 文件页起始目录和截图/录屏保存目录.

### P2: 后续扩展

- 剪贴板自动同步及方向设置, 常驻监听和断线会话管理.
- 录屏质量与性能采样频率等需要设备能力适配的参数.

### 不做

- 图片/文件/富文本剪贴板传输, 剪贴板历史, 云同步和多设备广播.
- APK 安装, root, 新增网络服务或完整投屏功能.
- 自动粘贴到手机输入框, 自动打开识别链接, 绕过锁屏或工作资料策略.

## 跨任务验收

- [x] 设置可在未连接设备时打开和修改, 偏好重启后保留.
- [x] 旧主题和布局选择可迁移或保留, 页面与设置中的同一偏好一致.
- [x] 中文, 多行和表情文本可在电脑与当前手机之间手动双向传输.
- [x] 切换设备后旧读取结果不会写入电脑剪贴板, 不会把旧请求改发到新设备. 控制器测试通过, 真机切换未实测.
- [x] 无文本和失败不会清空目标剪贴板, 正文不会进入持久化文件或诊断输出. 图片拒绝/超限真机验证和代码检查通过.
- [ ] 应用信息和图标读取, 截图复制, 录屏和日志工作流保持可用.
- [x] 设置有真实桌面 UI 验证, 剪贴板有真实 Android 设备读写验证.
