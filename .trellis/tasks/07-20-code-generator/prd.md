# 新增二维码和条形码生成

## Goal

在现有 ADB GUI 桌面工具中增加一个独立的“生码”工作区, 让用户输入一条或多条文本后快速生成二维码或条形码并直接预览结果. 该功能是本地开发辅助工具, 不依赖 Android 设备, 也不是设备操作卡片.

## Confirmed Facts

- 当前顶层导航包含“工具”“日志”“应用”三个页签.
- “工具”页采用紧凑卡片网格, 不适合承载批量输入、参数和多结果预览.
- 项目为 React 19 + TypeScript + Tailwind CSS v4 的 Tauri 桌面应用, 当前未引入二维码或条形码生成依赖.
- 用户要求支持二维码和条形码, 支持批量输入, 默认按换行分割, 并允许自定义分隔符.
- 用户确认功能使用独立顶层页签, 每次选择二维码或条形码中的一种后生成当前类型.
- 用户要求大批量数据不能一次生成全部码图, 需要按可见范围懒生成.
- 用户确认输入和配置变化后不自动重算, 通过“生成”按钮或 `Ctrl+Enter` 明确更新结果.
- 用户确认分隔符提供常用预设和自定义模式, 数据内容原样保留, 单项失败不阻断整批, 页签切换保留当前会话状态.
- 用户确认码图可打开单项放大预览, 并使用左右方向键切换上一项和下一项.
- 生码逻辑应使用成熟前端库在本地完成, 不新增设备依赖或 Rust 后端接口.

## Requirements

### P0

- 在顶层导航增加独立的“生码”入口, 提供足够的输入和结果工作区.
- 提供二维码和条形码两种生成模式, 默认选择二维码; 用户选择模式后批量生成当前类型, 条形码使用 Code 128.
- 提供多行文本输入区, 默认每个非空行生成一个结果.
- 分隔符提供换行、逗号、分号、制表符和自定义预设; 自定义模式按用户输入的完整非空字面值分割, 不作为正则表达式解释.
- 输入和配置先作为草稿编辑, 仅在点击“生成”或按下 `Ctrl+Enter` 时提交为新的结果快照.
- 只忽略分隔后长度为 0 的项目; 其余内容保留首尾空白、重复项和输入顺序, 不静默裁剪、去重或重排.
- 清晰显示解析后的有效条数、空输入和无效输入反馈.
- 在同一页面展示批量结果, 每项同时显示原始数据和对应码图.
- 大批量结果使用虚拟滚动, 只生成当前可见范围及少量滚动缓冲区内的码图, 离开范围后释放对应渲染节点.
- 单项无法编码时在原位置显示错误, 其他有效项继续生成.
- 点击结果打开单项放大预览; 预览显示当前位置和总数, 支持可见的上一项、下一项、关闭按钮, 支持 `ArrowLeft`、`ArrowRight` 和 `Escape` 键盘操作, 到达首尾时不循环. 无法编码的项目在预览中继续显示对应错误.
- 切换到其他顶层页签再返回时保留草稿和最近一次生成结果; 关闭应用后清空, 不写入磁盘持久化.
- 码图在亮色和暗色主题下都保持可扫描的白底黑码.

### Out of Scope

- 不向 Android 设备发送生成的码图.
- 不引入在线生成服务或上传用户输入.
- 首版不提供图片下载、批量打包、复制图片或导出能力.
- 不跨应用重启保存输入或生成结果.
- 不在首版支持二维码容错级别、颜色、Logo 或条形码制式等高级样式配置.

## Acceptance Criteria

- [x] 用户可从顶层“生码”页签进入功能, 且无需选择或连接设备.
- [x] 默认按换行解析输入, 只忽略零长度项目, 输入多条非零长度数据时生成相同数量的结果.
- [x] 换行模式兼容 `LF`、`CRLF` 和 `CR`; 逗号、分号、制表符和自定义模式按对应完整字面值解析.
- [x] 编辑输入、分隔符或码类型时不自动替换现有结果; 点击“生成”或按下 `Ctrl+Enter` 后才使用最新配置更新结果.
- [x] 用户可在二维码和 Code 128 条形码之间切换, 明确触发生成后结果使用新模式更新.
- [x] 非空项目的首尾空白、重复项和顺序保持不变, 生成内容与输入项目逐字一致.
- [x] 每个结果都显示对应原始数据, 不发生项目错配.
- [x] 输入数千条数据后, 页面不会同时挂载全部码图, 滚动到后续结果时才生成对应码图且输入区仍可操作.
- [x] 空输入和自定义分隔符为空时不生成并显示行内错误; 单个二维码或条形码无法编码时只在对应结果显示错误.
- [x] 点击任意结果可打开大图预览; 左右按钮和方向键按顺序切换且不越过首尾, `Escape` 关闭预览; 无法编码的项目显示相同的单项错误.
- [x] 切换顶层页签后返回, 输入、配置和结果保持不变; 应用重启后不恢复这些数据.
- [x] 生成图片可被常见扫码工具识别.
- [x] 页面在项目支持的亮色、暗色主题和最小窗口尺寸下无内容遮挡或不可达操作.
