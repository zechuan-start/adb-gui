# 文件应用与生码偏好

## 目标与来源

为现有文件/应用/生码工作区增加长期偏好, 页面快捷项和统一设置保持一致, 下次使用不必重复调整. 来源为 [第二批设置](../09-05-settings-phase-two/prd.md), 第一实施子任务, 不依赖本机保存目录改造.

## 已确认与推荐默认

- 用户确认生码记住上次类型/分隔符, 清空只删除正文与结果.
- 现有文件默认目录为 /sdcard/Download, 已显示隐藏文件, 目录优先且名称升序.
- 现有应用默认按应用名升序, 全部候选排序字段已在 AppInfo 中.
- 以下新增选项与默认值已由用户授权按实施顺序执行.

## P0 需求

### 文件浏览

- 排序维度为名称/修改时间/大小, 支持升降序, 默认名称升序.
- 目录优先和显示隐藏文件分别为开关, 均默认开启, 保持现有显示习惯.
- 文件顶部提供排序菜单、方向图标和设置入口, 隐藏开关在设置分组调整.
- 关闭隐藏文件显示只过滤以点开头的名称. 不依据文件属性或扩展名猜测隐藏规则, 不遗漏用户显式输入的隐藏目录内容.
- 排序不改变当前路径/选中项/预览/传输对象. 隐藏所选项时清除该选择和预览, 不保留不可见对象的操作入口.
- 支持起始目录预设: 下载目录、内部存储根目录、相机目录, 以及自定义 Android 绝对路径.
- 默认下载目录. 运行中修改仅影响下一次进入文件页、切换到新设备或点击主页, 不自动跳转当前页面.
- 不记录上次浏览目录. 同一偏好用于所有设备, 不自动创建设备目录.
- 起始目录不可访问时显示真实失败, 允许修改地址/重试, 并提供显式打开下载目录动作; 不自动回落或改写偏好.

### 应用列表

- 提供应用名称/包名/安装时间/更新时间/APK 大小五种排序和升降序.
- 默认应用名称升序. 切换排序维度保留当前升降序, 方向图标有明确 tooltip.
- 搜索只过滤, 排序只排列当前数据. 选择继续按包名绑定, 操作目标不随行号改变.
- 名称规则沿用中文友好自然排序. 元信息缺失项在数值排序中始终放最后, 同值按应用名/包名稳定排列.
- 排序不刷新设备列表、不重新加载全部图标、不改写应用缓存或清空搜索词.

### 生码

- 页面和设置共用持久化类型/分隔符/自定义分隔符, 默认二维码+换行.
- 自定义分隔符只做字面分割, 保留现有行为, 不额外解释转义字符.
- 允许编辑尚未填完的自定义分隔符, 为空时给出明确错误并阻止生成, 不偷偷回到换行模式.
- 参数变化保留当前正文和已生成结果, 不自动重新生成. 结果与当前输入/参数不一致时沿用过时提示.
- 点击生成才用此时正文和参数生成新批次, 旧结果快照不被设置修改重解释.
- 清空只清正文/错误/结果/预览, 保留类型与分隔符. 重启恢复参数, 正文和结果为空.
- 生码分组恢复默认只恢复参数, 不删除当前正文和结果, 不自动触发生成.

### 设置整合

- 唯一弹窗新增文件/应用/生码分组, 页面设置图标直接定位对应组.
- 七分组保持原生 modal、方向键/Tab/Escape 和焦点恢复. 未连接设备可编辑偏好.
- 单组重置只影响当前组, 存储失败保留旧有效偏好并反馈.

这些功能均直接解决第一批延期的重复操作, 所以纳入 P0.

## 不做

- 新的设备 API/DEX, 应用系统包显示、排序权限或自动安装动作.
- 浏览历史、每设备偏好、记忆选择/搜索词, 多选、文件删除、下载目录配置.
- 生成正文/结果持久化、模板历史、批量自动生成, 性能进程排序.

## 验收标准

- [ ] 第一批配置加载补齐新组默认, 旧设置不变, 新偏好重启保留.
- [ ] 所有排序维度/方向/同值/缺失值/中英文与数字名称稳定, 不原地修改数据数组.
- [ ] 文件目录优先独立于升降序, 隐藏开关和选中/预览/传输行为正确.
- [ ] 排序/隐藏切换不触发 list/getInstalledApps 或重启已有图标批次.
- [ ] 起始目录变更不跳当前页; 下次激活/Home 使用新值, 无效路径可显式恢复.
- [ ] 缓存先显示/新数据到达时继续用当前排序, 所选包名仍正确.
- [ ] 生码参数即时一致且持久, 清空/分组重置/过时提示符合上述行为.
- [ ] 自定义空分隔符/多字符/中文/换行/字面反斜杠通过解析回归.
- [ ] 无设备/存储损坏/写入失败有准确状态, 不保存正文或运行数据.
- [ ] 1200 x 800/900 x 600 双主题, 工具栏和七分组不溢出, 键盘操作完整.
- [ ] macOS 原生重启与 Android 文件/应用读取冒烟通过, 其他平台覆盖明确记录.
