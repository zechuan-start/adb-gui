# 第二批设置与个性化偏好

## 产品与目标

继续完善 Android 桌面工作台的长期偏好, 减少浏览文件/应用和批量生码时的重复调整, 允许将截图与录屏保存到常用本机目录. 沿用第一批轻量设置弹窗和现有页面, 不增加后台或新的工作区.

## 已确认

- 用户确认第一批设置已完善, 明确要求开始第二批规划.
- 用户选择生码采用 "记住上次选择": 页面修改类型和分隔符即保存, 清空只删除输入和结果.
- 第一批延期范围为文件/应用排序, 隐藏文件, 生码偏好, 文件起始目录, 截图与录屏保存目录.
- main 分支保留第一批功能和 README 未提交改动. 2026-09-05 用户明确批准由主线程安排并执行第二批, 不主动提交或归档.

## 代码基线

- 文件页进入/重新激活时打开 /sdcard/Download, 后端已返回隐藏文件, 固定目录优先和名称升序.
- 应用列表已有名称/包名/安装时间/更新时间/APK 大小, 固定按名称排序, 无需新增 DEX 查询.
- 生码默认为二维码+换行, 当前清空会同时重置类型和分隔符.
- 截图和录屏各自实现 Pictures/ADB GUI 的目录选择, 录屏路径在开始时固定. 当前录屏拉取失败后仍清理手机文件, 必须随目录可配置能力修正.
- 详细代码依据见 [research.md](./research.md).

## P0 推荐范围

| 分组 | 第二批能力 | 默认行为与价值 |
| --- | --- | --- |
| 文件 | 名称/修改时间/大小排序, 升降序, 目录优先, 显示隐藏文件 | 名称升序, 目录优先开启, 显示隐藏文件开启; 保持升级前视图, 便于查找目标文件 |
| 文件 | 起始目录: 下载目录/内部存储/相机目录/自定义绝对路径 | 默认下载目录; 下次进入文件页或点击主页生效, 不打断当前导航 |
| 应用 | 名称/包名/安装时间/更新时间/APK 大小排序, 升降序 | 默认名称升序; 用已有元信息定位最近安装或较大应用 |
| 生码 | 记住二维码/Code 128, 分隔符方式和自定义分隔符 | 默认二维码+换行; 页面与设置即时一致, 清空不重置偏好 |
| 截图与录屏 | 选择一个公共本机保存目录, 单独恢复系统默认目录 | 默认 Pictures/ADB GUI; 三个自动打开开关继续独立工作 |
| 保存失败 | 录屏失败保留手机源文件, 提供重试保存/另存为/明确放弃 | 防止自定义目录断开或权限变化造成丢失, 是目录设置的配套能力 |

上述能力承接第一批延期范围, 已按用户授权实施并验证, 不加入无消费者的占位设置.

## 共同要求

- 偏好对本机应用全局生效, 不按设备建立第二套偏好或保存浏览历史.
- 复用唯一设置存储, 保留第一批有效值及原 theme/ui 所有权, 缺失新增字段按明确默认值补齐.
- 页面快捷控件与设置共用同一有效偏好. 修改列表外观不触发 ADB 刷新, 不改变真实选择对象或缓存.
- 未连接手机时可编辑偏好. 原生目录选择需要桌面环境, 设备起始路径可离线填写.
- 本机目录与手机目录分组清晰, 不将本机路径发送给手机 shell, 不自动创建设备目录.
- 配置损坏或写入失败沿用第一批明确反馈, 不静默回退或显示已保存.
- 不保存生码正文/结果, 应用搜索词, 设备列表, 目录浏览历史, 传输进度或剪贴板正文.

## P1/P2 与不做

- P1: 分设备起始目录/记住上次浏览位置, 截图与录屏独立目录, 日志/报告默认目录, 性能进程排序持久化.
- P2: 剪贴板自动同步, 录屏质量/时长, 性能采样频率, 设置导入导出及跨机器同步.
- 不迁移或删除旧截图/录屏, 不调整文件下载每次选择位置的工作流, 不扩大文件系统权限, 不改 DEX/剪贴板协议.
- 不改变安装/卸载/清数据确认. 仅新增放弃尚未保存录屏的显式确认, 提示手机原文件删除不可撤回.

## 跨任务验收

- [ ] 升级第一批配置后, 原主题/日志/性能/启动/打开行为保留, 新偏好使用明确默认值.
- [ ] 页面快捷项与设置即时一致, 重启后保留, 恢复本组默认不影响其他分组和用户内容.
- [ ] 文件排序/过滤不改变列表真实对象, 起始目录修改不触发当前页面跳转或重复加载.
