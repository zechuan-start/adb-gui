# 统一设置入口与偏好持久化

## 产品与价值

为现有 Android 开发测试桌面工作台提供统一设置弹窗. 用户在一个位置调整长期习惯, 重启后仍可使用相同偏好. 不把设置做成新的工作区或后台管理页.

## 来源与依赖

- 总任务: [统一设置与手动剪贴板](../09-05-settings-clipboard/prd.md).
- 用户已选择先做核心设置和剪贴板, 暂不加入文件/应用排序, 生码默认值及目录选择.
- 本任务先于剪贴板实施, 不依赖新 DEX, 可独立验收.

## 规划时基线

- 主题和各页面日志显隐/日志高度已经保存到本地.
- Logcat 现有视图设置支持列预设, 显示列, 换行, 堆栈折叠和行距, 重启后不保留.
- 性能页已有切换页面继续采集, 默认关闭, 未持久化.
- 截图保存后固定打开图片并定位目录, 录屏保存后固定打开视频.
- 应用当前恢复上次工作区, 启动后自动检查更新.

## P0 需求

### 统一入口

- 左侧栏底部提供设置入口, 按通用, 日志, 性能, 截图与录屏分组.
- 页面设置入口打开同一个弹窗的对应分组. 未连接手机也能修改偏好.
- 保留搜索, 筛选, 暂停/继续及日志换行/折叠快捷操作的就地入口, 同一选项与设置保持一致.
- 修改后立即保存, 每组可恢复默认. 不设置手动保存按钮或清理用户数据的混合操作.

### 通用与启动

- 主题支持跟随系统, 亮色和暗色, 保留原用户选择.
- 启动页支持恢复上次工作区或指定现有六个工作区之一. 默认恢复上次, 修改从下次启动生效.
- 启动检查更新可关闭, 默认开启. 关闭后下次启动不发起检查, 不影响已经由用户主动开始的更新安装.

### 日志与性能

- 集中并保存 Logcat 标准/紧凑列预设, 七个显示列, 自动换行, 自动折叠崩溃堆栈和宽行距.
- 可以集中设置六个工作区是否显示日志, 与侧栏日志显隐操作一致.
- 保留原日志面板高度和显隐值. 调整显示偏好不清空日志或改变暂停/选中状态.
- 保存性能页切换页面继续采集的开关. 默认关闭, 开启后切页继续采集, 用户手动暂停优先.

### 截图与录屏

- 分别提供保存截图后打开图片, 保存截图后定位目录, 保存录屏后打开视频三个开关.
- 三项默认开启, 保持升级后的原行为. 关闭只影响自动打开, 文件仍正常保存.
- 截图并复制不保存文件, 不打开外部程序, 不受截图保存开关影响.
- 文件保存成功但外部打开失败时准确提示, 不丢弃已保存文件.

这些能力均属于已有配置整合或已确认的核心行为开关, 因此纳入 P0.

## P1/P2 与不做

- P1: 文件/应用排序, 隐藏文件显示, 生码默认参数, 文件起始目录和本地保存目录, 后续另行规划.
- P2: 设置导入导出, 录屏质量, 性能采样频率, 剪贴板自动同步设置.
- 本版不保存搜索词, 日志正文, 设备会话, 暂停状态或剪贴板正文.
- 不修改设备权限, 应用数据和系统配置, 不新增主题配色编辑器或占位开关.

## 验收标准

- [ ] 设置在无设备, 离线及正常连接状态均可访问.
- [x] 1200 x 800/900 x 600 和亮色/暗色下无溢出遮挡, Tab/Escape/焦点返回正确.
- [x] 设置入口均打开唯一弹窗, 旧独立视图弹层和主题入口整合到位.
- [x] 旧主题, 工作区日志显隐和日志高度保留; 新偏好重启后保留.
- [x] 日志快捷换行/折叠与设置即时一致, 日志正文/seq/暂停状态不被重置.
- [x] 指定启动页只在冷启动应用, 运行中修改设置不强制跳页.
- [x] 关闭启动检查更新后冷启动没有 check 调用, 在途结果失效, 不自动下载. 单测通过, 原生未抓包.
- [ ] 性能后台采集开关跨重启保存, 切页与手动暂停行为符合定义.
- [x] 截图四种打开/定位组合均正确, 关闭行为不阻止真实 PNG 保存.
- [x] 录屏开/关自动打开均生成非空 MP4, 手动停止和自然结束都正确应用设置.
- [x] 截图并复制仍生成电脑端图片剪贴板内容, 不意外保存或打开文件.
- [x] 存储失败/损坏能看到明确错误, 不静默显示已保存或覆盖原数据. store 测试通过, 原生存储未故障注入.
- [x] 恢复本组默认只改变该组偏好, 不清除日志, 图片, 应用缓存或其他分组.
