# 截图录屏保存目录与失败保留

## 目标与依赖

允许用户为截图和录屏选择常用本机保存目录, 并在目录不可用时保留未保存录屏以便恢复. 来源为 [第二批设置](../09-05-settings-phase-two/prd.md). 在 [文件应用与生码偏好](../09-05-browsing-codegen-settings/prd.md) 验收后串行实施, 共用最终设置 schema 和弹窗.

## 本次继续与验收环境

- 2026-09-05 用户要求查看当前任务并开始执行, 明确允许直接使用 Android Studio 模拟器.
- 初次核对时指针落在本子任务, 前置子任务仍为 planning. 用户随后明确授权主线程安排并执行, 已先完成文件/应用/生码子任务独立检查, 再启动本任务.
- 本轮 Android 功能验收使用已有 Pixel_10 模拟器. 模拟器实测可以满足本轮设备链路验收, 独立注明真实手机 ROM 和其他 Android 版本未覆盖, 不以真机缺席阻塞实现.
- 环境基线和检查上限见 [preflight.md](./preflight.md). 基线不代表新增设置或失败恢复功能已经通过验收.

## 已核对现状

- 截图和录屏默认都保存到 Pictures/ADB GUI, 代码却各有一份目录解析函数.
- 录屏开始时保存 local_path 到会话, 三个自动打开开关已由第一批统一设置控制.
- stop_screen_record 当前先移除会话, 不论 pull 是否成功都会尝试删手机源文件, 然后才检查本机文件大小.
- 原生 dialog 插件已可用, 无需增加前端文件系统读写权限.

## P0 需求

### 公共本机保存目录

- 在现有截图与录屏分组增加一个公共目录设置, 截图和录屏共用, 不增加两个默认目录.
- 默认仍为系统 Pictures/ADB GUI. 目录行显示实际路径, 选择按钮打开本机原生目录选择器, 可取消.
- 通过选择器选择已有目录, 不要求输入本机路径, 不自动附加第二层 ADB GUI 子目录.
- 目录偏好持久化, 单独的恢复默认图标只恢复目录, 不修改三个自动打开开关.
- 恢复截图与录屏整组默认会恢复该目录和三个打开开关, 不迁移或删除已有文件.
- 未连接手机可选择本机目录. Browser 预览不伪造目录选择成功.
- 默认 Pictures 无法解析时显示清晰错误并允许用户选择目录, 不静默改存 /tmp.
- 自定义目录被移动/卸载/权限改变后不自动创建其替代路径或改存别处, 保存失败明确提示.

### 生效时点与文件行为

- 截图在点击保存时固定目录和打开选项, 操作中修改设置只影响下一次.
- 录屏在开始时固定目录, 录制中修改目录只影响下一段. 保存后自动打开仍在停止/保存时取值.
- 已保存路径的打开/定位按钮始终操作结果路径, 不能从最新设置重算历史路径.
- 截图并复制不落盘, 不受保存目录影响; 日志、报告、设备下载位置保持现有规则.
- 真实写入成功后才提示保存, 自动保存不覆盖同名用户文件. 另存为覆盖已有文件必须由系统保存对话框明确确认. 显示最终路径, 不以目录选择成功代表可持续写入.

### 录屏保存失败恢复

- 拉取/校验/发布本机文件失败时保留手机源文件和当前恢复会话, 错误包含准确阶段和目标.
- 不自动重复保存. 显示重试保存、另存为、放弃保存三个明确动作, 禁止未处理时开始新录屏.
- 重试使用原会话目录; 另存为通过原生保存对话框选择本次文件位置, 不改变公共目录偏好, 取消不改变会话.
- 成功拉取并验证完整、非空本机文件后再清理本段手机源, 自动打开失败不影响保存成功.
- 手机源清理失败要提示源文件仍保留, 不将已成功本机保存报为丢失, 也不自动再次拉取.
- 放弃保存需要确认会丢弃当前恢复并尝试删除手机未保存文件. 取消保持原态; 手机离线导致删除失败时仍可按明确的放弃意图释放会话, 反馈残留设备/路径而不宣称删除成功.
- 所有恢复动作绑定原会话和设备, 切设备或异步对话框迟到时不能作用到新录屏.
- 本轮仅承诺当前应用进程内恢复. 退出时不主动删除未保存源, 但不持久化恢复队列或承诺下次启动自动找回.

失败保留不是额外录屏管理功能, 是自定义目录在权限/卸载边界下可用的必要条件, 纳入 P0.

## 不做

- 截图与录屏独立目录, 日志/报告/下载默认目录, 按设备分目录, 自定义命名模板, 自动迁移旧文件.
- 新录屏编码参数/采样率/画质/时间限制, 自动重试、后台恢复队列或跨启动录屏管理.
- 更改系统目录权限、自动提权、扩大 Tauri 文件系统权限, 安装新的手机辅助应用.

## 验收标准

- [ ] 原配置无新增目录字段时沿用默认, 新目录重启后保留, 取消选择/存储失败保留原偏好.
- [ ] 自选中文/空格目录保存真实 PNG/MP4, 恢复目录不改三个打开开关, 全组恢复范围正确.
- [ ] 默认目录缺失、自定义目录失效、无权限/目标冲突明确失败, 不落到其他目录或覆盖已有文件.
- [ ] 录屏中改目录, 当前段留在原目录, 下一段去新目录, 打开选项仍按保存时值执行.
- [ ] 本机保存失败不会删除手机源, 不清掉恢复会话或自动循环重试.
- [ ] 重试/另存为/取消/确认放弃/断线/迟到对话框均符合会话归属, 不重复 pull 或误删源.
- [ ] 保存成功后手机清理失败与外部打开失败分别反馈, 已保存文件仍可访问.
- [ ] 自然结束、手动停止和切设备结束共用保存路径, 每段自动保存至多提交一次.
- [ ] 当前 Android 模拟器验证失败保留后另存为成功, 并验证源最终清理; 不损害已有设备文件, 单独记录未覆盖的真机范围.
- [ ] 双主题/双尺寸目录行不溢出, 原生对话框返回焦点正确, 第一批截图复制与开关回归通过.
