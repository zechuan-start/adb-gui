# 设备文件双向传递

## 产品形态

这是 ADB GUI 中面向当前已连接 Android 设备的文件工作台. 它用于浏览设备目录并完成电脑与设备之间的文件传递, 不是裸 ADB 命令终端, 也不是完整替代系统文件管理器的双栏资源管理器.

## 目标与用户价值

- 连接并选中在线设备后, 用户可以直接查看设备上 ADB 有权限访问的目录和文件.
- 用户可以把电脑文件上传到当前设备目录, 也可以把设备文件下载到电脑.
- 用户可以在应用内查看常见图片, 无需先手工执行 `adb pull`.
- 现有 APK 工具中的“推送”能力并入文件工作台, APK 工具回归只负责安装 APK, 避免同一传输能力存在两个入口.

## 已确认事实

- 当前前端是 React 19 + TypeScript, Tauri 桥接集中在 `src/lib/tauri.ts`.
- 当前后端是 Rust + Tauri 2, 设备作用域 ADB 调用集中通过 `run_adb_with_serial` 执行.
- 当前“推送”位于 `AppManager.tsx` 的 APK 工具内, 一次选择或拖拽一个本地文件, 后端固定上传到 `/sdcard/Download/<原文件名>`.
- 当前没有设备目录列表、通用 `adb pull`、设备文件元数据模型或图片预览接口.
- 截图、录屏和 Bugreport 已有“保存到本地并打开/显示”的交互模式, 可复用本地文件选择和反馈习惯.
- ADB 只能访问当前 `adbd` 身份有权限的路径. 非 root 设备无法保证读取 `/data` 等受保护目录.

## 范围

### P0: 双向文件工作流

- 新增独立“文件”工作台, 仅在已选设备在线时可操作.
- 在顶部一级页签新增“文件”入口, 使用完整工作区; 上方为路径与操作栏, 主区约 70% 为文件列表、约 30% 为图片预览或文件详情.
- 默认进入设备下载目录 `/sdcard/Download`, 显示当前路径、上级入口、文件名、类型、大小和修改时间.
- 当前路径使用可编辑路径栏展示, 支持复制完整路径和输入其他绝对路径后跳转.
- 支持进入子目录、返回上级目录、通过面包屑跳转和手动刷新.
- 支持在当前设备目录中新建子目录.
- 支持选择一个或多个本地文件并上传到当前设备目录; 遇到同名文件时自动生成不冲突的新名称, 不覆盖设备原文件.
- 支持将本地文件拖入工作台并上传到当前设备目录.
- 支持选择一个设备文件并通过系统保存对话框下载到电脑.
- 下载保存对话框默认定位到电脑系统“下载”目录并使用设备端原文件名, 用户可临时修改目录和文件名.
- 文件列表默认目录优先、名称升序并显示隐藏文件; 单击条目选中并显示详情, 双击目录进入, 双击普通文件不执行动作.
- 文件详情提供复制完整设备路径和下载入口.
- 支持单击预览 PNG、JPEG、WEBP 和 GIF; 预览文件上限为 20 MiB, 超限时只显示文件信息和下载入口; 预览失败时明确显示错误, 不伪装成功.
- 多文件上传按顺序执行, 显示当前序号、总数、文件名及逐项成功或失败结果; P0 不提供字节级进度和取消.
- 目录加载、上传、下载和预览均提供加载态、成功反馈和带上下文的失败反馈.
- 切换设备时关闭旧预览并重新加载新设备的默认目录, 不沿用上一台设备的文件状态.
- 将 APK 工具现有“推送”模式及其入口移除, APK 工具只保留 APK 安装; 通用上传统一由文件工作台负责.

### P1: 文件管理动作

- 重命名文件或目录.
- 删除文件或目录, 必须二次确认并明确影响范围.
- 多选后批量下载或删除.

### P2: 后续增强

- 文本文件预览.
- 文件排序、搜索和筛选.
- 传输队列、逐项进度、取消和失败重试.
- 目录递归上传与下载.
- 收藏常用设备路径.

## 约束

- 所有设备操作必须绑定当前选中的设备序列号, 不允许调用无 `-s <serial>` 的 ADB 命令.
- 远端路径拼接、路径规范化和 shell 参数转义由 Rust 后端统一负责, 前端不拼接命令字符串.
- 目录列表必须使用结构化 Tauri 返回值, 前端不解析原始 `ls` 文本.
- 不能依赖 root 权限. 遇到权限不足、路径不存在、设备断开或传输失败时必须显式失败.
- 图片预览数据只在当前查看期间保留, 切换文件、目录或设备后释放, 不建立隐藏的长期缓存.
- 保持现有跨平台支持范围: macOS、Windows 和 Linux.

## 验收标准

- [x] 选中在线设备后, 打开文件工作台能看到默认设备目录的内容; 空目录显示明确空状态.
- [x] 默认路径为 `/sdcard/Download`; 路径栏可复制, 输入 ADB 可访问的绝对路径后可跳转, 无权限或不存在时保留原目录并显示错误.
- [x] 目录项和文件项可区分, 目录可进入, 上级入口和面包屑可返回, 刷新后内容与设备一致.
- [x] 在当前目录新建子目录后, 新目录立即出现在列表中; 无权限或同名冲突时明确失败.
- [x] 上传一个普通文件后, 文件出现在当前设备目录且文件名保持不变.
- [x] 上传目标存在同名文件时, 新文件按 `名称 (序号).扩展名` 生成可用名称, 原文件内容不被覆盖.
- [x] 一次选择或拖入多个普通文件后, 每个文件都有可确认的成功或失败结果.
- [x] 下载一个设备文件时由用户选择本地保存位置, 完成后可在系统文件管理器中显示该文件.
- [x] 下载保存对话框默认使用系统“下载”目录和设备端原文件名, 且允许用户修改两者.
- [x] 列表按目录优先、名称升序显示并包含隐藏文件; 选择条目后可复制其完整设备路径.
- [x] 选择受支持图片后能看到实际图片内容; 不支持格式或读取失败时不会显示过期预览.
- [x] 大于 20 MiB 的图片不会载入预览数据, 但仍可查看元数据和下载.
- [x] 设备离线、无权限、路径不存在、新建目录同名和 ADB 失败均显示可理解的错误.
- [x] 切换设备不会继续显示或操作上一台设备的目录、文件或预览.
- [x] APK 工具只保留安装能力, 原固定上传到 `/sdcard/Download` 的入口不存在; 文件工作台可进入 `Download` 并完成同等上传.
- [x] Rust 单元测试覆盖远端路径、目录列表解析和错误映射; 前端测试覆盖设备切换、目录导航和传输状态; `cargo test`、严格 Clippy、前端测试及生产构建通过.
- [x] 使用真实 Android 设备完成浏览、上传、下载和图片预览冒烟测试.

## 暂不纳入

- 绕过 Android 权限限制或自动获取 root 权限.
- MTP、无线局域网文件服务或云同步.
- 音频、视频播放器和办公文档渲染.
- 文件内容编辑.
- 保证支持包含换行符等极端文件名; 常见 UTF-8 文件名、空格和中文必须支持.
