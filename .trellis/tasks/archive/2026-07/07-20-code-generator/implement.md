## 风险和回滚点

- `App.tsx` 是共享顶层导航文件, 仅增加联合类型、页签项、组件 import 和条件渲染.
- Canvas 生成库可能对超长或非 Code 128 字符抛错, 必须保留单项错误边界, 不能让整个结果树中断.
- 虚拟行高度和二维码双列数量必须保持一致; 若响应式列数变化, 同步重建虚拟行并测量.
- 回滚范围为新增前端模块、依赖和 `App.tsx` 页签接入, 无后端或持久数据回滚.
