# 第二批设置总体设计

## 产品形态

保留现有六个工作区和唯一 SettingsDialog. 新增文件/应用/生码三个设置分组, 保留通用/日志/性能/截图与录屏. 菜单选排序维度, 图标按钮切方向, 开关控制目录优先/隐藏文件, 文件夹图标调用本机目录选择器.

~~~text
+ 设置 ---------------------------------------------------- x +
| 通用 | 文件 | 应用 | 生码 | 日志 | 性能 | 截图与录屏          |
|                                                              |
| 当前分组选项, 内容区域独立滚动                                |
| 路径字段占整行, 右侧选择目录/恢复默认图标                      |
|                                                              |
| [恢复本组默认]                                      [关闭]   |
+--------------------------------------------------------------+
~~~

- 保留弹窗宽 min(720px, viewport - 32px), 高 min(620px, viewport - 32px), 内容独立滚动.
- 七分组使用可换行 tablist, 不挤出底部操作; 首尾焦点循环, 方向键/Home/End 导航覆盖全部分组.
- 文件/应用/生码顶部增加对应设置图标, 高频排序和生码参数继续原位操作. 900px 最小窗口下工具栏允许第二行, 不挤压路径输入与列表.
- 路径占独立一行, 可选择复制/换行, tooltip 可查看全值. 普通设置只显示必要标签/状态/错误, 不添加说明书式文案.

## 状态与初始化

- 延用 adb-gui-settings 和 version 1, 按缺失字段兼容策略新增 files/apps/codegen/capture, 不新建配置文件或 Rust 常驻偏好副本.
- 子任务 1 添加 files/apps/codegen; 子任务 2 添加 capture.directory. 每一步回归上一阶段有效配置.
- theme, adb-gui-ui, logcat/performance 运行态归属不变. 恢复默认只影响当前分组.
- 页面列表/正文/生成结果是运行态, 排序/过滤/生码参数从唯一偏好派生, 不用双向 effect 复制.
- 非法新字段走原有配置错误路径, 不静默改回其他目录或参数.
- 回退到第一批时旧 decoder 可忽略新增字段, 但旧版重新保存可能丢弃新增字段; 不承诺跨版本往返保留, 不删除配置作为回滚.

## 跨层数据流

1. 文件/应用: 原始数据 -> 用持久偏好派生显示列表 -> 虚拟列表, 业务动作继续使用 path/packageName. 修改偏好不重新调用 ADB.
2. 设备起始目录: 保存绝对路径或 null(既有下载目录) -> 下次激活/Home 读快照 -> listDeviceDirectory -> Rust 路径规范化和范围校验.
3. 生码: 页面/弹窗修改唯一偏好 -> 保留正文 -> 生成时组合参数和正文 -> 冻结结果. 清空只清正文与结果.
4. 截图: 点击时读目录和打开选项快照 -> Rust 唯一目录解析与保存 -> 返回真实路径/打开结果.
5. 录屏: 开始时固定目录与会话身份 -> 停止/自然结束保存 -> 验证成功后清理源. 自动打开选项仍在保存时读取.

## 依赖与修复范围

- 先实施浏览/生码, 排序只依赖已有 AppInfo/DeviceFileEntry, 不新增 DEX 或设备查询.
- 保存目录抽取两份 Rust 函数为唯一 helper. 移除该范围内静默 /tmp/ADB GUI 回落, Pictures 不可解析时提示选择目录.
- 录屏配套失败保留、重试/另存为/放弃和阻止自动循环重试. 不顺带改录屏信号/编码参数/ADB 选择.
- 旧录屏 spec 要求 pull 失败仍删源, 与本次需求冲突. 实施时更新该章节, 不沿用旧清理合约.

## 平台与验证

- 手机路径始终为 Android 绝对路径, 本机目录使用宿主 Path API.
- macOS 覆盖中文/空格路径与 LaunchServices 启动; Windows 覆盖盘符/文件占用; Linux 覆盖 Pictures 缺失/目录权限.
- Browser 的原生目录按钮禁用, 不伪造选择成功. Browser 验证布局/普通偏好, Tauri 验证 IO.
- 真机只在测试专用目录造样例, 临时产物放 /tmp 或缓存目录, 测试后恢复偏好.
