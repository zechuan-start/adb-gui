# Blueprint 应用外壳与主题基础

## 产品形态

这是 Blueprint Quiet 翻新的基础子任务. 它只建立所有页面共享的视觉 token、主题、导航和设备上下文外壳, 不重做各业务页面内部功能.

## 目标

- 将当前顶部页签外壳替换为原型的左侧索引栏和 54 px 顶栏.
- 建立离线可用的 IBM Plex 字体和亮暗两套 Blueprint token.
- 将现有 `system | light | dark` 主题能力完整暴露给用户并修复降级边界.
- 为后续持久 Logcat 和工具页提供唯一页面状态与布局边界.

## P0 要求

- 左侧索引栏固定 168 px, 包含品牌图号、工具/应用/文件/生码/解码五个页面入口、日志开关插槽和主题三档控件.
- 移除独立 Logcat 页面入口, 但本子任务只提供日志工作区插槽, 具体面板由 Logcat 子任务实现.
- 顶栏包含设备选择、设备刷新、无线连接和前台 Activity. 状态颜色覆盖在线、未授权、离线和无设备.
- 所有现有页面仍可访问, 页面内部功能和 state 不因外壳切换而重置.
- 新增 `ui` store 统一管理 `activePane`、`logOpenByPane`、日志高度、铺满和已读位置.
- 主题选择持久化. system 模式实时响应系统变化, `matchMedia` 缺失时明确使用亮色.
- 字体随应用构建本地提供, 不使用运行时网络字体.
- 页面背景采用 22 px 双向网格, 日志面板区域由后续子任务使用不透网格的专用底色.

## 状态要求

- 页面日志默认值为 `tools/apps/files = open`, `codegen/decoder = closed`.
- 切页自动退出日志铺满状态, 但不重置该页日志开关.
- 设备切换继续触发现有 Activity、process map 和页面数据更新, 不新增平行设备选择逻辑.
- 无设备、未授权和离线设备可以在选择器中看到, 设备相关页面和工具用 `isOnlineDevice` 判断能力.

## 不做

- 不实现 Logcat 工具栏、列表、堆栈折叠或复制.
- 不重排工具页模块.
- 不重新设计应用、文件、生码和解码页内部布局.
- 不复制原型内联 SVG 或模拟设备数据.

## 验收标准

- [ ] `1200x800` 与 `900x600` 下索引栏和顶栏尺寸稳定, 页面没有重叠和非预期横向滚动.
- [ ] 五个页面入口可达, 原有功能组件仍挂载在对应页面.
- [ ] Logcat 不再作为独立页面出现, 工作区存在可供后续面板接入的底部插槽.
- [ ] system、light、dark 三档均可切换、持久化并显示当前选中态.
- [ ] 系统主题变化只在 system 模式立即生效, `matchMedia` 缺失不会阻止应用启动.
- [ ] 在线、未授权、离线和无设备在设备选择器中有不同且非仅靠颜色的表达.
- [ ] 主题切换、页面切换和日志开关不播放布局动画.
- [ ] 所有新增按钮具有 tooltip、`aria-pressed` 或当前页语义以及可见 `focus-visible`.
- [ ] `corepack pnpm test` 和 `corepack pnpm build` 通过.

## 约束

- `App.tsx` 只保留启动监听和页面组合, 外壳拆到 `src/components/layout/`.
- 继续使用 `lucide-react`.
- 现有 store 是业务事实源, 新 `ui` store 只保存显示状态.
- 不在 token 外散落亮暗主题硬编码色值.
