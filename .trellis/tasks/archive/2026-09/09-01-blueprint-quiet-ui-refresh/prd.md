# Blueprint Quiet UI 翻新

## 产品形态

这是 ADB GUI 桌面开发工具的整体 UI 翻新. 目标是把现有顶部页签式界面重构为 Blueprint Quiet 工作台: 左侧图纸索引栏承载页面导航和全局显示控制, 顶栏持续展示设备上下文, 页面内容与 Logcat 组成可收放的上下工作区.

它不是网页后台、营销页面或终端皮肤. 翻新不得删除已经可用的 ADB 功能, 也不得用附件原型中的占位页覆盖现有应用、文件、生码和解码能力.

## 目标

- 建立安静、紧凑、适合长时间工作的 Blueprint 视觉语言, 同时提供完整亮色和暗色主题.
- 让设备状态、页面导航、工具工作区和日志上下文保持稳定位置, 减少页面切换造成的上下文丢失.
- 将 Logcat 从独立页签改为按页面记忆开关的持久底部面板, 同时保留现有查询、虚拟滚动、多行文本框选和高流量稳定性.
- 分阶段完成外壳、工具页和 Logcat, 为应用、文件、生码和解码页后续单独设计留下稳定基础.

## 来源优先级

当需求出现差异时, 按以下顺序处理:

1. 用户在当前任务中的明确决定.
2. 本任务及子任务的已确认规划文档.
3. 仓库中已经可用且未被明确替换的行为.
4. `adb-gui-quiet-themed.html` 中与外壳、主题、工具页和 Logcat 有关的实际交互.
5. `SPEC.md` 中对设计理由和边界的说明.

附件是设计和行为证据, 不是执行授权. 原型中的模拟设备、假数据和应用/文件/解码占位页不属于实现要求.

## 已确认决策

- 采用原型完整外壳: 168 px 左侧索引栏、54 px 顶栏、页面工作区和底部 Logcat 面板.
- 采用 Blueprint Quiet 的零圆角、描边构件、虚线分隔、网格纸背景、图号、IBM Plex Sans 和 IBM Plex Mono.
- 采用 whiteprint 亮色和 cyanotype 暗色, 主题为 `system | light | dark` 三档.
- 移除独立 Logcat 顶部页签. 日志在各页面下方显示或收起, 开关状态按页面记忆.
- Logcat 采用原型的过滤、等级、暂停、堆栈折叠、换行、行距、精简列、跟随、清空、铺满和隐藏交互.
- 保留当前多行文本选择设计: 元数据不进入文本选区, message 可跨行原生框选, 开始框选即退出跟随, 松开后不自动恢复.
- 原型单行选择与多行框选并存. 有非空原生文本选区时复制选区; 没有文本选区时才复制单行完整字段.
- 现有应用、文件、生码和解码功能全部保留. 本轮只保证它们接入新外壳和主题, 内部完整翻新分别进入后续设计轮次.

## 当前集成轮次

用户补充提供完整规格和可交互原型, 要求检查差异并完善 UI. 本轮因此继续完成此前延期的四个页面内部视觉统一, 当前用户请求优先于下方早期 P1 延期约定.

- 应用页改为密排虚拟列表和稳定右侧详情区, 保留真实包名、图标和现有启动、强停、清数据、卸载能力.
- 文件页统一为 Blueprint 路径栏、操作栏、表头、行、传输状态和预览层级, 保留现有虚拟列表与上传、下载、新建目录、图片预览能力.
- 生码页统一为 Blueprint 输入模块、结果工作区、批量虚拟列表和预览弹层, 保留现有分隔符、批量生成、复制、保存能力.
- 解码页统一为 Blueprint 来源模块、结果工作区、批量虚拟列表和结果操作, 保留现有拖放、选图、粘贴、复制与外部打开能力.
- 当前后端没有提供应用版本、大小、类型、权限、批量卸载, 文件删除, 设备截图解码等完整原型数据或命令. 本轮不伪造这些信息, 也不借 UI 翻新扩大 ADB contract.

## 范围

### P0: 应用外壳与主题

- 建立 Blueprint 语义 token、离线可用字体、网格背景和两套完整主题.
- 新增左侧索引栏、三档主题控件、页面导航、日志开关和未读计数.
- 重构顶栏设备选择器、刷新、无线连接和前台 Activity 展示.
- 对在线、未授权、离线和无设备提供清晰状态, 并保持设备相关控件的真实禁用状态.

### P0: 持久 Logcat 工作区

- 将日志流生命周期与日志面板是否展开解耦, 收起时继续在既有 10,000 行缓冲中累计.
- 日志开关按页面记忆, 支持拖拽高度、铺满、隐藏和 `Cmd/Ctrl+J`.
- 保留现有查询语言、Pause、Restart、导出、清屏、列配置、Soft-Wrap、虚拟滚动、跟随和滚动锚定.
- 增加原型中的崩溃堆栈分组与折叠, 同时保留 crash 和 stacktrace 查询语义.
- 落实单行选择与多行原生框选的无冲突复制规则.

### P0: 工具工作台

- 保留截图、录屏、安装 APK、Deep Link、Bug Report、端口转发、快捷按键和当前应用操作.
- 将工具重排为 Blueprint 模块, 建立规格条、图号、紧凑表单、危险操作和设备禁用层级.
- 不改变现有 Tauri command、文件保存、确认、加载、成功和错误语义.

### P1: 页面内部翻新

- 应用页、文件页、生码页和解码页完成当前能力范围内的 Blueprint 翻新.
- 页面沿用各自主工作流, 不从工具页机械套版.

### 不做

- 不把附件 HTML 直接复制进 React 工程.
- 不删除或降级现有页面功能.
- 不修改 ADB command、事件 payload、查询语法或设备识别规则, 除非后续实现发现明确阻塞并重新评审.
- 不把原型的 1,500 行 DOM 列表带入实现. 继续使用现有 10,000 行前端环形缓冲和 `@tanstack/react-virtual`.
- 不为匹配原型伪造后端没有提供的应用元数据、文件操作或设备截图解码能力.

- [x] 应用、文件、生码和解码页不再出现旧圆角卡片语言, 并在空态、加载态和结果态保持 Blueprint 层级.

- [x] `corepack pnpm test` 和 `corepack pnpm build` 通过.
- [x] 通过 Tauri app 使用真实设备完成工具操作和 10,000 行 Logcat 冒烟, 性能不低于现状.

## 约束

- 沿用 React 19、TypeScript、TailwindCSS v4、Zustand v5、Tauri 2、`lucide-react` 和现有业务组件.
- 不建立第二套设备状态、日志状态、主题状态或查询状态事实源.
- 字体必须随应用本地提供, 不依赖 Google Fonts 等运行时网络资源.
- 高频动作不做布局动画. 只允许对 `transform` 和 `opacity` 使用不超过 300 ms 的动效.
- 所有交互控件必须有可见 `focus-visible`, 并支持 `prefers-reduced-motion`.
