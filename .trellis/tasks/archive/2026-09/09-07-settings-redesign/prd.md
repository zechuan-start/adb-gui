# 设置面板整体重构

## Goal

把设置弹窗从 "六页 tab 各自一屏" 改成 "一页可滚动的设置清单 + 左侧锚点索引", 并把全部控件收敛到一套规则. 目标是解决用户反馈的 "用起来不舒服": 密度失衡, 控件规则不统一, 紫色标记语义不明, 外壳层级过重.

不新增偏好项, 不改偏好语义与默认值, 不改 `adb-gui-settings` 存储结构, 不升 `SETTINGS_VERSION`, 不动设备命令. macOS 原生菜单仅增加打开现有设置面板的入口.

## 背景与已确认

- 2026-09-07 根据五张设置截图规划整体重构, 确认保留全局弹窗, 移除搜索框, 取消组内二级小标题, 随后完成前端实现.
- 保留应用 / 文件 / 生码的 `openSettings(section)` 快捷入口, 由单页滚动清单统一承载 "全部恢复默认" 与改动标记.
- 2026-09-08 确认修复错误横幅隐藏, 底部菜单裁剪和索引 Tab 焦点衔接, 增加 macOS `Cmd + ,`, 并完成原生 App 验证与替换安装.
- 2026-09-08 追加确认设置内容区的淡网格背景与标题初始焦点. 后续改动沿用本任务, 不创建新任务; 完成后统一整理, 提交和推送.

## 现状问题 (来自截图与源码)

| 问题 | 现象 | 根因位置 |
| --- | --- | --- |
| 密度失衡 | 应用 1 行, 生码 2 行, 面板大片空白; 日志 十几项需滚动 | 每个 section 独占一屏, `SettingsDialog.tsx` 按 tab 切换渲染 |
| 控件规则不统一 | 开关是原生 checkbox 靠右; 日志列与工作区是 checkbox 网格靠左; 分段控件三种长相 (主题图标组 / 标准紧凑小号 / 码类型全宽深色) | `SettingToggle` 用 `input[type=checkbox]`; 各 section 手写分段按钮; `GeneratorPreferences` 用 `grid-cols-2` 铺满 |
| 标记语义不明 | 导航与标签旁 6px 紫色方块, 无说明, 无就地重置 | `SettingRowLabel` 与导航 `dirty` 只渲染 `bg-note` 小方块, `title="已改动"` 在 `aria-hidden` 元素上 |
| 外壳过重 | 搜索框 + 两个恢复按钮 + X + 关闭, 20 项设置套系统级设置的壳 | header 搜索, footer 三按钮 |
| 文案 | 说明文字 `text-ink3` 偏浅; "清空结果不会重置这里" "改变排序不会重新读取应用信息" 是实现细节 | `settingsSections.ts` description |
| 排序方向不易发现 | 孤立的小箭头图标按钮 | `SortPreferences.tsx` |

## Requirements

### R1 信息架构: 单页滚动 + 锚点索引

- 六个分组 (通用, 日志, 截图与录屏, 文件, 应用, 生码) 在一个滚动容器内依次排列, 每组一个标题行, 组内直接是设置行. 取消组内二级小标题 (显示 / 保存位置 / 截图 / 录屏 / 排序与显示 / 起始目录), 层级固定为 分组 > 设置行.
- 左侧导航改为锚点索引: 点击滚动到对应分组; 滚动时高亮当前所在分组 (scrollspy); 保留 ArrowUp / ArrowDown / Home / End 键盘操作.
- `openSettings(section)` 的语义保持: 打开弹窗并滚动到该分组. 工作区快捷入口 (文件 / 应用排序旁的齿轮, 生码页, 性能页, 日志菜单, 侧栏) 不改调用方式.
- 分组顺序与标签仍只来自 `SETTINGS_SECTIONS`.

### R2 控件规则收敛为四类

| 值类型 | 控件 | 位置 | 适用行 |
| --- | --- | --- | --- |
| 布尔 | 真实 switch (轨道 + 滑块, `role="switch"`), 整行 label 可点 | 行右 | 检查更新, 后台采集, 自动换行, 折叠堆栈, 宽行距, 截图后打开, 截图后定位, 录屏后打开, 文件夹优先, 显示隐藏文件 |
| 单选 <= 3 项 | 分段控件, 一种尺寸 (h-8, 文字 + 可选图标), 不铺满 | 行右 | 主题, 日志显示格式, 码类型, 排序方向 |
| 单选 > 3 项 | `BlueprintSelect` | 行右 | 启动页面, 排序字段, 分隔符, 起始目录预设 |
| 多选集合 | chip 组 (`aria-pressed` 按钮, 可换行) | 标签下方 (堆叠行) | 日志显示列, 显示日志的工作区 |

- 需要附加输入的行 (自定义分隔符, 自定义起始目录, 保存目录路径) 使用堆叠行: 标签在上, 控件与输入在下, 与其他行共用同一条分隔线与内边距.
- 设置区内不再出现原生 `input[type=checkbox]`.
- 排序方向从图标按钮改为 升序 / 降序 分段控件, 与排序字段下拉并排.
- 内容列限制最大宽度, 标签与右侧控件的视线距离有上限.

### R3 改动标记与重置

- 非默认值的行在标签后显示文字标签 "已修改" (可读, 有 `title`), 取代 6px 紫色方块.
- 每个分组标题行右侧有 "恢复默认" 按钮, 只在该组存在已修改行时显示; 执行 `sectionResetPlan(section)` 的全部目标 (settings 字段 + 主题 / 工作区可见性), 各 store 独立复位.
- "全部恢复默认" 移到滚动内容末尾, 作为安静的文字按钮, 保留二次确认.
- 左侧索引不再显示改动标记.
- 去掉 footer, 去掉 "关闭" 按钮, 去掉搜索框. 关闭只保留 header 的 X 与 Escape.

### R4 文案与视觉

- 说明文字提高对比 (`text-ink3` -> `text-ink2`).
- 删除实现细节类说明: "清空结果不会重置这里", "改变排序不会重新读取应用信息"; "启动时检查更新" 说明缩短为 "只在启动时检查一次".
- 分组标题行使用现有 Blueprint 数据字体小号大写样式, 与 `ToolModule` 编号风格一致.
- 弹窗保持 Blueprint 方角, 硬阴影, 不透明 `bg-paper`.
- 内容区复用 22px Blueprint 网格, 亮色强度为主界面的 60%, 暗色为 50%; 标题, 索引, 控件和下拉菜单保持实色.

### R5 不变量 (来自现有 spec, 必须保持)

- 禁用范围按存储归属: 只有 `adb-gui-settings` 拥有的控件在 `!available` 时禁用; 主题与工作区可见性始终可改.
- 标签与说明只来自注册表; 未知行 id 抛错.
- 快捷控件与弹窗控件写同一个 settings action (生码页的码类型 / 分隔符, 文件与应用工具栏的排序).
- 焦点边界, Escape 关闭并还原触发焦点, 设置打开时屏蔽工作区热键.
- 首次打开聚焦无边框的标题, Tab / Shift+Tab 再进入首尾控件并保留可见焦点提示; 切换分组时不重新聚焦标题.

### R6 macOS 菜单与滚动边界

- macOS 应用菜单提供 "设置…" 与 `Cmd + ,`, 通过 `open-settings` 事件打开现有弹窗; Windows 不注册该菜单和快捷键.
- 设置读取失败时, 错误原因与恢复操作固定在滚动区外.
- 从索引按 Tab 进入目标分组的第一个可用控件; 全部禁用时聚焦分组自身.
- 下拉菜单按视口与滚动祖先的交集决定上下展开方向和可用高度, 并在滚动或缩放窗口时更新; 不使用造成原生 WebKit 绘制异常的缩放入场动画.

## 非目标

- 不新增 / 删除任何偏好字段, 不改默认值, 不升 schema 版本.
- 不改 Rust 设备命令与 mock.
- 不做 Windows 设置打开热键, 不做移动端断点.
- 不迁移应用 / 文件 / 生码偏好到各工作区弹出层.
