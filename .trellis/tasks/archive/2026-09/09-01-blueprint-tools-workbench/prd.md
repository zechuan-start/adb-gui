# Blueprint 工具工作台翻新

## 产品形态

这是 ADB GUI 的高频工具工作台翻新. 用户在同一页面完成截图、录屏、安装、链接调试、报告、端口、按键和当前应用操作. 页面应紧凑、可扫读并持续显示当前设备上下文, 不是卡片陈列页.

## 目标

- 将现有八个工具按 Blueprint Quiet 语言重排为描边模块, 减少圆角卡片和同权重灰块.
- 在页面顶部建立设备异常状态条和设备规格条, 让工具的可用性有明确上下文.
- 保留所有现有业务行为、确认流程、文件路径、toast 和错误反馈.

## P0 范围

- 页面顺序为状态条、设备规格条、工具模块网格.
- 在线设备显示规格条. 未授权和离线设备显示状态条及可获得的信息; 无设备不渲染规格条.
- 工具模块使用统一 header、图标、标题、图号和 body 边界.
- 保留截图、录屏、安装 APK、Deep Link、Bug Report、端口转发、快捷按键和当前应用.
- 模块编号稳定为 A-01 至 A-08, 只用于定位和视觉语言, 不进入业务状态.
- 设备不可用时真实禁用相关控件, 不允许点击后才提示失败.
- 截图、录屏、文件选择、保存、打开、显示目录、清数据和卸载等现有反馈与确认不变.
- 规格条复用设备详情加载结果, 不与设备信息弹层分别发起和保存两份相同状态.

## 不做

- 不改 Tauri command 参数或返回值.
- 不新增工具, 不调整业务优先级.
- 不把每个字段拆成独立卡片.
- 不将应用、文件、生码或解码页套用工具模块布局.

## 验收标准

- [x] 八个现有工具都在新工作台出现, 入口、状态和主要动作没有丢失.
- [x] `1200x800` 下模块密度接近原型, `900x600` 下网格自然降列且不发生内容覆盖.
- [x] 在线、未授权、离线和无设备状态下, 状态条文案、规格条和 disabled 状态一致.
- [x] 生码和解码不依赖设备, 不受工具页设备禁用逻辑影响.
- [x] 设备详情只存在一个加载结果, 设备切换后旧详情不会闪现到新设备.
- [x] 危险动作继续保留现有确认, 普通成功和错误继续使用统一 toast.
- [x] 亮暗主题下模块描边、次级文字、输入框和状态色均清晰.
- [x] 所有按钮在 hover、active、disabled 和 focus-visible 下可辨.
- [ ] 真实设备完成八类工具主要路径冒烟.
- [x] `corepack pnpm test` 和 `corepack pnpm build` 通过.

## 约束

- 复用现有业务组件和 handler, 允许提取共享视图壳, 不复制 command 调用.
- 不创建嵌套卡片.
- 工具网格使用稳定 `minmax` 轨道, 动态状态不得改变模块宽度.
- 禁用判断继续使用 `getDeviceBySerial` 与 `isOnlineDevice`.
