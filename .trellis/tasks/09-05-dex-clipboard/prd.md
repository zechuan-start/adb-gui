# 复用 DEX 的手动双向剪贴板

## 产品与价值

在 ADB GUI 工具工作台提供按需双向文本传输, 用户复制一段文本后点击一次操作, 即可在另一端粘贴. 保持轻量工具体验, 不新增剪贴板管理器或常驻同步控制台.

## 来源与依赖

- 总任务: [统一设置与手动剪贴板](../09-05-settings-clipboard/prd.md).
- 用户明确要求扩展现有应用信息 DEX. 第一版手动同步, 自动同步后续再做.
- 在统一设置子任务通过后串行实施, 复用最终工作台结构. DEX 通道不依赖新的设置存储.

## 规划时基线与实施结果

- 现有 DEX 随 Tauri 打包, 通过 ADB 下发到手机并使用 app_process 调用 Android API, 无需安装 APK.
- 电脑端已有 clipboard-manager 插件, 可以补齐文本读取和写入入口.
- 当前 Android 16 手机的 com.android.shell 已获后台读取剪贴板权限. 实施中已修正 shell Context 的 opPackage, 真机 get/set/readback 通过.
- Android 会校验调用包名/UID, 锁屏与工作资料策略不能因使用 DEX 而忽略.

## P0 需求

### 手动操作

- 工具页提供发送到手机和复制到电脑两个操作, 显示当前目标设备.
- 发送到手机仅写入手机剪贴板, 用户自行粘贴, 不向当前输入框注入内容.
- 复制到电脑只把手机的文本写入电脑剪贴板, 不打开编辑器或页面.
- 只在用户点击时读取源内容. 两个方向共用单次操作忙状态, 防止重复触发.
- 支持中文, 多行, 表情, 引号及其他合法文本, 保留前后空白和换行形式.
- 第一版只传单个纯文本值. 超过明确文本上限时提示过长, 不截断内容.

### 结果与设备上下文

- 仅操作点击时选中的在线设备. 未授权/离线/无设备时禁用操作.
- 切换设备或断线后, 尚未提交的旧写入被取消, 旧响应不显示为新设备的结果.
- 已经提交给原设备/电脑系统的写入可能完成, 不承诺撤回; 绝不改发到新设备.
- 成功反馈必须基于确认的写入结果. 超时/响应丢失时提示结果未确认, 不自动重复写入.
- 空字符串或无法取得文本时不清空目标剪贴板. 纯空白文本不被误认为空内容.
- 锁屏, 权限和 ROM 不兼容明确失败, 不自动修改手机设置或换成模拟输入.

### 与现有能力共存

- 继续使用同一个 DEX, 保留应用信息与图标读取能力.
- 用户在应用图标加载期间发起剪贴板操作, 不因整个图标查询持锁而等待其结束.
- 不保存剪贴板正文/历史, 不把正文写入命令参数, 日志, 截图说明或错误提示.
- 截图并复制图片和其他现有桌面复制功能保持可用.

这些是完成真实双向文本工作流的必要能力, 全部纳入 P0.

## P1/P2 与不做

- P1: 根据实际需求扩展快捷键和设备兼容范围, 单独定义工作资料/多用户合约.
- P2: 自动同步开关, 同步方向, 常驻监听, 会话恢复及冲突处理.
- 不做图片/文件/富文本传输, 历史记录, 云同步, 多设备广播或投屏.
- 不自动粘贴, 安装 APK, 请求 root, 修改权限/输入法, 使用固定 Binder 调用编号或完整 scrcpy-server.
- 当前范围仅主用户普通应用的剪贴板; 不能确认支持的上下文时明确报错, 不读取其他用户空间.

## 验收标准

- [ ] 两个方向都在真实 Tauri + 当前 Android 16 手机上完成复制和实际粘贴验证.
- [x] 中文, CRLF/LF, 表情, 前后空白, 引号, 反引号, 美元符号和协议标记文本原样往返.
- [x] 同内容可成功处理, 空字符串不清空目标, 图片无文本有明确提示.
- [x] 文本上限内不截断, 超限在写入前被拒绝并提示.
- [x] 无设备/离线/未授权操作禁用, 忙时重复点击不产生第二次传输.
- [x] A -> B -> A, 断线重连和传输别名切换使旧响应失效, 未提交的旧内容不会写入电脑或手机. 控制器测试通过, 真实切换未实测.
- [x] 超时, JSON/版本错误, 非零退出及写入验证失败不会显示成功, set 不自动重试.
- [ ] 锁屏及不支持的用户/资料上下文明确拒绝, 不更改手机系统设置.
- [x] Java 源码与打包 DEX 同步, 只下发同一个助手 DEX, 无 APK 安装或后台同步进程.
- [ ] 应用元信息和图标仍能读取, 并发部署无覆盖运行文件问题, 剪贴板不等图标长任务锁.
- [x] 本地与设备端助手/管道按预算退出, 不留下未处理的操作.
- [x] 剪贴板正文不进入持久化和诊断输出, 截图复制图片仍可用.
